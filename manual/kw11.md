# KW11-L — line time clock

[← Manual index](README.md) · device name: **`KW11`** · source: `10.02_devices/2_src/dl11w.cpp` (class `ltc_c`)

## What it represents

The KW11-L is the PDP-11's line time clock: it interrupts at the frequency of the mains supply — 50
or 60 Hz — and is what every operating system on the machine uses as its scheduling tick. On a
DL11-W board it shares the card with the [serial line unit](dl11w.md), which is why it lives in the
same source file; QUniBone presents it as a device of its own.

Without the KW11 enabled, most operating systems will boot but never schedule: RT-11 will sit at
its prompt, UNIX will appear to hang. Enabling it is part of nearly every example script.

Rather than counting real time from scratch, the emulation tracks world time since the last INIT
and the number of power-supply edges produced so far, and adjusts, so the tick rate stays correct
over long runs even though it is produced by a Linux thread.

## Bus register

| Offset | Name | Meaning |
|---|---|---|
| +0 | `LKS` | Line Clock Status: bit 6 interrupt enable, bit 7 the clock monitor flag set at each tick. |

DEC defaults:

| Parameter | Value |
|---|---|
| `base_addr` | `777546` |
| `slot` | 3 |
| `intr_vector` | `100` |
| `intr_level` | 6 |

## Parameters

Besides the [common device parameters](common-parameters.md):

| Name | Short | Type | Meaning |
|---|---|---|---|
| `Line clock frequency` | `freq` | unsigned | Tick rate in Hz: 50 or 60. |
| `LTC input enable` | `ltc` | bool | 1 = allow the LTC input signal to update `LKS`. |

Both names contain spaces, so use the short forms: `p freq 50`, `p ltc 1`.

## Typical use

```
en KW11
sd KW11
p freq 50
```
