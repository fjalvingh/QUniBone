# KE11-A — Extended Arithmetic Element

[← Manual index](README.md) · device name: **`ke`** · **UNIBUS only** · source: `10.02_devices/2_src/ke11.cpp`

## What it represents

The KE11-A is the Extended Arithmetic Element of the early PDP-11s — an option board that adds
multiply, divide, normalize and multi-bit shifts to a processor whose instruction set has none of
them. It is not an instruction set extension: the CPU has no new opcodes, it *writes operands into
the board's registers and reads the result back*. Software written for the KE11 (early FORTRAN and
UNIX libraries, for instance) does exactly that.

This is why the KE11 is a plain bus device here and not part of the CPU emulation: it behaves like
one, both on a real PDP-11 and in QUniBone, and it works the same whether the processor is a
physical one or the emulated [CPU20](cpu20.md)/[CPU34](cpu34.md).

The board does not interrupt.

## Bus registers

| Offset | Name | Meaning |
|---|---|---|
| +0 | `DIV` | Divide: writing the divisor performs the division. |
| +2 | `AC` | Accumulator — the high-order half of the operand/result. |
| +4 | `MQ` | Multiplier-Quotient — the low-order half. |
| +6 | `MUL` | Multiply: writing the multiplier performs the multiplication. |
| +10 | `SCSR` | Step Count and Status Register. |
| +12 | `NOR` | Normalize. |
| +14 | `LSH` | Logical Shift: writing the shift count performs the shift. |
| +16 | `ASH` | Arithmetic Shift. |

The arithmetic registers are "active on DATO" (and, where writing a value triggers the operation,
on DATI too), so the ARM side computes the result while the bus cycle is held.

## Parameters

The KE11 adds no parameters of its own; see the [common device
parameters](common-parameters.md). DEC defaults:

| Parameter | Value |
|---|---|
| `base_addr` | `777300` |
| `slot` | 10 |
| `intr_vector` | — (does not interrupt) |
| `intr_level` | 5 |

## Typical use

```
en ke
sd ke
e            # examine all registers
```
