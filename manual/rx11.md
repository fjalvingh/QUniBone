# RX11 / RXV11 — single-density floppy controller

[← Manual index](README.md) · device name: **`rx`** · source: `10.02_devices/2_src/rx11.cpp`

## What it represents

The RX11 is the UNIBUS interface to an RX01 floppy subsystem: two 8" single-density drives in one
box, with all the intelligence — command decoding, sector buffer, head positioning — in a
microprocessor board inside that box. QUniBone reproduces exactly that split:

- **`rx`** — this page: the bus interface, two registers, programmed I/O one byte at a time.
- **[`rxbox`](rx0102ucpu.md)** — the microCPU board that actually executes the commands.
- **[`rx0`, `rx1`](rx0102drive.md)** — the two electro-mechanical drives.

| Variant | Bus | Notes |
|---|---|---|
| **RX11** | UNIBUS | Interrupt level 5. |
| **RXV11** | QBUS | Interrupt level 4. This is the one the QBUS build creates. No DMA — like the RX11 it moves data through `RXDB`. |

For the double-density RX02 subsystem with DMA, see [RX211/RXV21](rx211.md).

## Bus registers

| Offset | Name | Meaning |
|---|---|---|
| +0 | `RXCS` | Command and Status. Writing it starts a function; the GO bit is the RUN line to the microCPU. |
| +2 | `RXDB` | Multi-purpose Data Buffer. Every read moves the next byte out of the microCPU's buffer, every write moves one in. It is also where RXES and RXER appear after "Read Status" and "Read Error Register". |

## Parameters

The RX11 adds no parameters of its own; see the [common device
parameters](common-parameters.md). DEC defaults:

| Parameter | RX11 | RXV11 |
|---|---|---|
| `base_addr` | `777170` | `777170` |
| `slot` | 16 | 16 |
| `intr_vector` | `264` | `264` |
| `intr_level` | 5 | 4 |

The RX11 and the [RX211](rx211.md) have the same DEC default address and vector; they are given
different default slots only so that enabling both does not trigger a priority-slot conflict
warning.

## Drives

Two drives are created — `rx0` and `rx1` — both of type RX01, single density only, plus the
microCPU object `rxbox` that connects them to the controller. Enable the box and the drives you
want:

```
en rx                                     # controller
en rxbox                                  # the drive box microprocessor
en rx0
sd rxbox
p powerswitch 1                           # switch the drive box on
sd rx0
p image ../diskimages/rt11v03-1.rx01.dsk
```

The bootloader listing is `5_applications/bootloaders/dx.lst`. Complete examples are in
`5_applications/rt11.rx01` and `5_applications/lsx.rx01`.
