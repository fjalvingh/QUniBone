# M9312 — bootstrap / terminator ROM board

[← Manual index](README.md) · device name: **`M9312`** · **UNIBUS only** · source: `10.02_devices/2_src/m9312.cpp`

## What it represents

The M9312 is the UNIBUS bootstrap and terminator card: five ROM sockets, one holding the console
emulator and diagnostic PROM, four holding boot PROMs for whatever controllers the machine has.
After power-up it redirects the CPU's vector fetch into its own ROM, so the machine starts running
the console emulator or boots straight from a disk — the "auto-boot" of a PDP-11 without a front
panel.

QUniBone emulates all of it: the ROM contents sit in the IO page, and the power-up redirection is
reproduced by ORing `773000` onto the address lines after ACLO is negated. To avoid disturbing
manual EXAM/DEPOSIT with a halted CPU, that redirection lasts only 300 ms and only for the first
two DATI cycles, which are the CPU's PC and PSW fetch.

The diagnostic that tests this board is XXDP `ZM9BE0`.

## ROM sockets and their addresses

| Socket | Parameter | Address range | Size |
|---|---|---|---|
| Console emulator / diagnostic | `consemu_file` | from `765000` | 256 words |
| Boot ROM 1 | `bootrom1_file` | from `773000` | 64 words |
| Boot ROM 2 | `bootrom2_file` | from `773200` | 64 words |
| Boot ROM 3 | `bootrom3_file` | from `773400` | 64 words |
| Boot ROM 4 | `bootrom4_file` | from `773600` | 64 words |

An unpopulated socket still occupies its space in the IO page and reads back the fill pattern
`161777`, as on real hardware.

The two "registers" the device declares at `773024` and `773026` are the trap PC and PSW. They are
not registers of a controller but ROM cells with a special function: reading them is how the
emulation counts the power-up bus cycles that drive the boot redirection.

## Parameters

Besides the [common device parameters](common-parameters.md):

| Name | Short | Type | Access | Meaning |
|---|---|---|---|---|
| `consemu_file` | `cer` | string | writable | MACRO-11 listing (`.lst`, ak6dn.com format) for the console emulator and diagnostic ROM. `-` or empty means no ROM in the socket. |
| `bootrom1_file` | `br1` | string | writable | Listing for boot ROM 1. |
| `bootrom2_file` | `br2` | string | writable | Listing for boot ROM 2. |
| `bootrom3_file` | `br3` | string | writable | Listing for boot ROM 3. |
| `bootrom4_file` | `br4` | string | writable | Listing for boot ROM 4. |
| `bootaddress_label` | `bl` | string | writable | The MACRO-11 label, taken from the loaded listings, that the machine is to auto-boot from. Empty means no auto-boot. |
| `bootaddress_info` | `bi` | string | read-only | The resolved boot address — the power-on PC — or `DISABLED`. |

A ROM file must contain the addresses its socket expects; after loading, the ROM's base address is
taken from the file. The `bootaddress_label` is resolved against the labels of the listings that
are actually plugged in, which is why `bootaddress_info` is worth reading back after setting it.

DEC defaults:

| Parameter | Value |
|---|---|
| `base_addr` | `773024` (the trap vector; `773200` for an 11/60) |
| `slot` | 31 |
| `intr_vector` | — (the board does not interrupt) |
| `intr_level` | — |

## Original PROM listings

`5_applications/bootloaders/` holds the original DEC M9312 PROM listings for exactly this purpose:

| File | ROM |
|---|---|
| `23-248F1.lst` | console / diagnostic PROM — plug in with `p cer` |
| `23-751A9.lst` | `DL` boot PROM — [RL11](rl.md) |
| `23-756A9.lst` | `DK`/`DT` boot PROM — [RK03/RK05](rk.md) and TU55/TU56 |
| `23-767A9.lst` | `DU` boot PROM — [MSCP](mscp.md) |

## Typical use

```
en M9312
sd M9312
p cer ../bootloaders/23-248F1.lst      # console emulator
p br1 ../bootloaders/23-751A9.lst      # RL boot ROM
p bl  <label>                          # auto-boot entry from that listing
p bi                                   # check what it resolved to
pwr                                    # power cycle: the machine boots
```

A worked example is in `5_applications/m9312`, and
`5_applications/cpu20/cpu20_xxdp_m9312_rl0_dl11.sh` boots XXDP through the M9312 with the emulated
[CPU20](cpu20.md).
