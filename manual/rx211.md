# RX211 / RXV21 — double-density floppy controller

[← Manual index](README.md) · device name: **`ry`** · source: `10.02_devices/2_src/rx211.cpp`

## What it represents

The RX211 is the interface to an RX02 floppy subsystem: two 8" drives that can read and write both
single density (FM, as an RX01) and double density (MFM). Unlike the [RX11](rx11.md) it transfers
sector data by **DMA** instead of byte-by-byte through the data register.

As with the RX11, the subsystem is three objects:

- **`ry`** — this page: the bus interface with its two registers and the DMA channel.
- **[`rybox`](rx0102ucpu.md)** — the microCPU board inside the drive box.
- **[`ry0`, `ry1`](rx0102drive.md)** — the two drives, of type RX02.

| Variant | Bus | Notes |
|---|---|---|
| **RX211** (reported as `RY211`) | UNIBUS | Interrupt level 5. |
| **RXV21** (reported as `RXV12`) | QBUS | Interrupt level 4. This is the one the QBUS build creates. |

## Bus registers

| Offset | Name | Meaning |
|---|---|---|
| +0 | `RX2CS` | Command and Status. Writing it starts a function. After INIT not even DONE is set, because the subsystem is still initializing. |
| +2 | `RX2DB` | Multi-purpose Data Buffer: word count, sector, track and status, depending on the phase of the command. |

## Parameters

The RX211 adds no parameters of its own; see the [common device
parameters](common-parameters.md). DEC defaults:

| Parameter | RX211 | RXV21 |
|---|---|---|
| `base_addr` | `777170` | `777170` |
| `slot` | 17 | 16 |
| `intr_vector` | `264` | `264` |
| `intr_level` | 5 | 4 |

`slot`, `intr_level` and `intr_vector` are re-programmed into the DMA and interrupt requests when
changed, so this controller accepts changes to them.

The RX211 shares its DEC default address and vector with the [RX11](rx11.md); the differing default
slot only avoids a conflict warning when both are enabled at once.

## Drives

Two drives are created — `ry0` and `ry1` — of type RX02, plus the microCPU object `rybox`. Because
these are RX02 drives, their `density` parameter is writable (`SD` or `DD`):

```
en ry
en rybox
en ry0
sd rybox
p powerswitch 1
sd ry0
p density DD
p image ../diskimages/rt11v4.rx02.dsk
```

The bootloader listing is `5_applications/bootloaders/dy.lst`; a complete example is in
`5_applications/rt11.rx02`.
